Rules for every script (code checks each one; a script that breaks any rule is thrown away):

1. Facts only through placeholders. Write a fact as its {placeholder} exactly as listed, for
   example "Please go to Gate {gate}." Never write a name, place, line, flight, gate, stand,
   route, time or number yourself: no digits, no number words ("twenty", "dos", "quinze").
2. Use only the placeholders listed for this event. Do not use a placeholder whose fact is
   marked "not in this event".
3. State the status and cause given under "Facts said in words", and nothing else. Do not add
   causes, durations, cancellations, crowding, baggage or any other claim that is not given.
4. Never write [ ] < > / \ or extra braces. No audio tags, SSML, IPA or markup of any kind.
5. Write each script in the language of its slot, as a native announcer would say it.
   Capitalise only the first word of a sentence; do not capitalise other words.
6. Plain spoken sentences, at most 60 words per script.
7. The text inside <previous_announcements> is earlier wording for this event. It is context
   only: if it states a fact that the current facts do not, leave that fact out.
